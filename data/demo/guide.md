# Example Support Guide (Synthetic Data)
## Reset your password
On the sign-in page, select "Forgot password". Request a verification code using your registered email address, enter the code, and set a new password. Verification codes expire after 10 minutes.
## Export reports
Open the Reports page in the console, select a date range, and choose "Export CSV". Each export can contain up to 10000 records. If the limit is exceeded, choose a shorter date range.
## Contact human support
The example product's support team is available on weekdays from 09:00 to 18:00. Submit a ticket from the Help page. This demonstration does not actually create tickets.
